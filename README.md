# Стоит ли смотреть?

Прототип веб-приложения, которое по названию фильма или сериала собирает оценки с трёх популярных площадок (IMDb, Кинопоиск, Rotten Tomatoes) и предлагает вердикт «смотреть» или «не смотреть».

## Как использовать

1. Откройте файл `index.html` в браузере.
2. Введите название фильма или сериала и нажмите «Проанализировать» или клавишу Enter.
3. Приложение покажет среднюю оценку, подробности по каждой площадке и итоговый совет.

Для нескольких популярных тайтлов используются подготовленные данные. Для остальных названий оценки рассчитываются алгоритмически, чтобы сохранить дух «бота-рекомендателя» без подключения к внешним API.
