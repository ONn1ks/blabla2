# Стоит ли смотреть?

Прототип одностраничного приложения, которое по названию фильма или сериала
подтягивает рейтинги IMDb, Rotten Tomatoes и Metacritic через OMDb API и показывает
средний балл с вердиктом «смотреть» или «не смотреть».

## Как запустить

1. Откройте файл `index.html` в современном браузере.
2. Получите бесплатный ключ на [omdbapi.com/apikey.aspx](https://www.omdbapi.com/apikey.aspx)
   (достаточно режима *Free*).
3. В интерфейсе приложения раскройте блок «Подключить ключ OMDb» и вставьте ключ —
   он сохранится локально в браузере.
4. Введите название фильма или сериала и нажмите «Проанализировать» (или Enter).
5. Приложение загрузит доступные оценки, посчитает средний балл и предложит
   итоговый совет.

## Особенности

- Источники рейтингов — IMDb, Rotten Tomatoes и Metacritic. Если OMDb не вернул
  какой‑то из них, интерфейс покажет, откуда нет данных.
- Для популярных тайтлов добавлены короткие описания на русском — они
  подмешиваются к сводке после загрузки реальных рейтингов.
- Ключ OMDb хранится только в `localStorage` вашего браузера и не покидает
  устройство. Серверная часть не требуется.
- При проблемах с ключом или сетью приложение выводит диагностическое сообщение
  и предлагает повторить попытку.
